ResolveHub

Overview

ResolveHub is a customer support and ticket management platform designed to help teams track, organize, and manage customer support requests efficiently.

Tech Stack

Frontend: React, TypeScript, Vite

Styling: CSS

Version Control: Git

Features Implemented

Reusable ticket list component.

TypeScript models for tickets, statuses, and priorities.

Mock ticket data for development.

Dashboard displaying total, open, in-progress, and resolved ticket counts.

Ticket table showing ID, title, status, priority, assignee, and creation date.

Empty-state handling for tickets with no data.

Project Status

🚧 In Development — Currently building the frontend foundation. Future phases will introduce REST APIs, PostgreSQL, authentication, testing, and CI/CD pipelines.
